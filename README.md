# 服务概览与核心特点

青云梯（QingYunTi）是一款提供多地区节点连接的网络加速服务，主要通过订阅方式管理节点信息，用户购买套餐后可获取对应订阅内容，并在支持的客户端中进行配置。

根据公开套餐信息，青云梯主要特点包括：

* 支持多地区节点选择
* 提供不同流量规格套餐
* 节点采用多地区线路布局
* 部分线路采用 IPLC 专线架构
* 节点倍率统一为 1 倍
* 支持多客户端同时使用
* 提供 Windows、macOS、Linux、iOS、Android 等平台支持

青云梯节点覆盖亚洲、欧美等多个区域，可以根据用户所在地、访问目标以及网络环境选择合适线路。

适用用户包括：

* 日常网络访问用户
* 海外影音内容体验用户
* AI 工具使用用户
* 远程办公用户
* 多设备联网用户

具体线路质量和稳定性表现会受到运营商网络、地区环境、节点负载以及平台策略影响。
